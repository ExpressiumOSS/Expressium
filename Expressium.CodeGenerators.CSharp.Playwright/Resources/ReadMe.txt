# Overview

This solution is a test automation framework generated by Expressium for web application and API testing. A layered structure separates the application layer from the test layer, promoting reusability and maintainability:

- **Expressium.Coffeeshop.Web** — Application layer:
  - **Pages** — Page objects.
  - **Controls** — Page object control wrappers.
  - **Models** — Data models.
  - **Services** — API service objects.
- **Expressium.Coffeeshop.Web.Tests** — Test layer:
  - **UiTests** — Page-level UI tests.
  - **BusinessTests** — BDD scenarios written in Gherkin.
  - **ApiTests** — Service-level API tests.
  - **Infrastructure** — Framework management objects.
  - **Factories** — Test data generation.

## Getting Started

Restore and build the solution:

```bash
dotnet build
```

Install the Playwright browsers (run once, after building):

```powershell
cd .\$Company$.$Project$.Web.Tests\bin\Debug\net10.0
.\playwright.ps1 install
```

## Configuration

Runtime settings live in the test project's `Configuration.json` file, which controls common options including the target Url, credentials, BrowserType, Headless mode, timeouts, and toggles for logging, screenshots, videos, and traces.

You may add a local `Configuration.local.json` file to override configuration settings. This file is ignored in Git, so it is a safe place for machine-specific values and secrets that should not be committed.

## Running Tests

Run the full suite:

```bash
dotnet test
```

Run a specific category:

```bash
dotnet test --filter TestCategory="UiTests"
dotnet test --filter TestCategory="ApiTests"
dotnet test --filter TestCategory="BusinessTests"
```

Convenience scripts are also provided:

- `BuildRunTests.bat` — Builds and runs the UI, API, and Business test suites.
- `CodeGeneration.bat` — Launches Playwright Codegen against the target site to help author locators.

## Living Documentation

BDD results are published as a living documentation test report via the Expressium LivingDoc Reqnroll plugin, configured in `Reqnroll.json` file and generated to the output directory.
